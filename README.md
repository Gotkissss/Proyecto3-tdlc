# Proyecto 3 — Simulador de Máquinas de Turing

Teoría de la Computación · Universidad del Valle de Guatemala

Simulador de Máquinas de Turing de una cinta. Lee la descripción formal de una MT desde
un archivo YAML, simula las cadenas configuradas y muestra las descripciones instantáneas.
